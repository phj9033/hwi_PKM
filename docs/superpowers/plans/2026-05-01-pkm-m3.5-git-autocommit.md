# M3.5 — Git Auto-Commit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire automatic single-commit-per-mutation into every M2/M3 mutate command via the `post_mutation` chokepoint, with `pkm init` bootstrapping the git repo. Closes spec §6.6 step 4 ("git 자동 커밋") and the spec §3.1 mutate JSON contract (`git_commit` field).

**Architecture:** New `pkm/store/git.py` is a thin `subprocess.run(["git", ...])` wrapper exposing three functions: `is_git_repo`, `git_init`, `commit_paths`. The existing `pkm/_mutations.py:post_mutation` chokepoint (M2 log + M3 reindex) gains a fourth step that commits the changed paths plus `data/log.md` and `data/index.md` in a single git commit. `pkm init` calls `git_init` at the end of its scaffold step and creates an initial commit so the repo isn't born dirty. All seven existing M2 mutate command JSON outputs grow a `git_commit` field carrying the SHA returned from `post_mutation`. When `.git` is missing, every step warns to stderr and continues with `git_commit: null` — the filesystem stays the source of truth.

**Tech Stack:** Standard library `subprocess`. No new runtime deps. Tests reuse the M1/M2/M3 conftest (RSS cap, stub embedder).

**Spec reference:** `docs/superpowers/specs/2026-05-01-pkm-design.md` — §3.1 (JSON shape with `git_commit`), §6.6 (auto side-effects, step 4), §2 (gitignore rules). Master spec text remains canonical; M3.5 implements §6.6 step 4.

## Scope decisions (locked from brainstorming, 2026-05-01)

| # | Decision | Outcome |
|---|---|---|
| 1 | Behavior in non-git dirs | **Warn-and-skip.** stderr `warning: not a git repo, skipping commit`; mutate JSON has `git_commit: null`; exit 0. The filesystem is the SoT, git is auxiliary. |
| 2 | `pkm init` git initialization | **Auto `git init`.** Idempotent — no-op if `.git` already exists. Also seeds `.gitignore` (the M2 init.py already wrote it via `gitignore.template`; M3.5 verifies it's complete) and creates an initial commit `pkm init: <root>` so the working tree starts clean. |
| 3 | Commit message format | **`pkm <event.type>: <event.ref>`** — uses `LogEvent.type` (e.g. `capture.create`) + `LogEvent.ref` (e.g. `2026-05-01-foo`). Deterministic, grep-friendly. Same SoT as `data/log.md`. |
| 4 | `--no-git` flag | **Out of scope (M7 hardening).** spec §6.6 mentions a `--no-git` deny mechanism, but every mutate command would need a flag for an option that's always denied — not worth the surface area in M3.5. |

After M3.5, a user can:

```bash
pkm init                     # git init + initial commit (clean tree)
pkm capture create --slug … <<<"…"
                             # JSON includes "git_commit":"abc1234…"; git log -1 shows the commit
git log --oneline | head     # all M2/M3 mutations have their own commit
```

### Why these boundaries

- **`pkm/store/git.py`** holds all `subprocess.run(["git", ...])` calls. One module = one easily mocked seam for tests.
- **`post_mutation`** stays the single chokepoint. It now returns the new SHA (or `None`) so commands can plug it into JSON. The M2/M3 invariant ("every mutation calls post_mutation") becomes load-bearing for the spec contract, not just for log/TOC/reindex.
- **No call site in `commands/` calls git directly.** They go through `post_mutation`. This keeps the four side-effect steps strictly ordered.

```python
"""Git auto-commit primitives.

Thin wrapper over the `git` CLI via `subprocess.run`. Three functions:

- `is_git_repo(root)` — bool
- `git_init(root)` — idempotent; bootstraps `.git/` and basic config if missing
- `commit_paths(root, paths, message) -> str | None` — single commit; returns
  the 40-char SHA, or None if the repo is missing OR there was nothing to
  commit (idempotent re-runs).

The caller decides what to do with `None`. Master spec §6.6 step 4.
"""
from __future__ import annotations

import subprocess
from pathlib import Path


def _run(args: list[str], cwd: Path, *, check: bool = True,
         capture: bool = True) -> subprocess.CompletedProcess[str]:
    return subprocess.run(
        args,
        cwd=cwd,
        check=check,
        capture_output=capture,
        text=True,
    )


def is_git_repo(root: Path) -> bool:
    """Return True iff `root` is inside a git working tree."""
    if not (root / ".git").exists():
        return False
    try:
        out = _run(
            ["git", "rev-parse", "--is-inside-work-tree"],
            cwd=root, check=False,
        )
    except FileNotFoundError:
        # `git` not installed
        return False
    return out.returncode == 0 and out.stdout.strip() == "true"


def git_init(root: Path) -> None:
    """Bootstrap a git repo at `root`. Idempotent.

    If `.git/` already exists, do nothing. Otherwise:
      1. `git init -q`
      2. Set `init.defaultBranch=main` for the repo (so the first branch is
         predictable across user environments).
      3. If user.email / user.name aren't set globally, set repo-local
         defaults so the very first `pkm` commit doesn't fail with
         "Please tell me who you are."
    """
    if (root / ".git").exists():
        return
    _run(["git", "init", "-q", "-b", "main"], cwd=root)
    # Set repo-local user.email/name only if not already configured anywhere
    for key, fallback in (("user.email", "pkm@local"), ("user.name", "PKM")):
        existing = _run(["git", "config", "--get", key], cwd=root, check=False)
        if existing.returncode != 0:
            _run(["git", "config", key, fallback], cwd=root)


def commit_paths(root: Path, paths: list[str], message: str) -> str | None:
    """Stage `paths` (skipping missing ones) plus implicit log/index files,
    then create one commit. Returns the new SHA, or None if:
      - root is not a git repo, OR
      - nothing was staged (e.g. all paths were unchanged), OR
      - all paths were ignored by `.gitignore`.

    Does not raise on user-recoverable failures (returns None instead). Only
    raises for catastrophic problems (git CLI missing — surfaced by the caller
    via `pkm doctor`).
    """
    if not is_git_repo(root):
        return None

    # `git add -- <path>` succeeds even if the path is gitignored or missing,
    # but we explicitly filter missing paths so we don't pollute git's stderr.
    abs_paths = [str((root / p)) for p in paths if (root / p).exists()]
    if abs_paths:
        _run(["git", "add", "--", *abs_paths], cwd=root)

    # Check if anything is staged
    diff = _run(["git", "diff", "--cached", "--name-only"], cwd=root)
    if not diff.stdout.strip():
        return None

    _run(["git", "commit", "-q", "-m", message], cwd=root)
    head = _run(["git", "rev-parse", "HEAD"], cwd=root)
    return head.stdout.strip()
```

```python
"""Single chokepoint for the auto side-effects every mutation must trigger.

M2: append-to-log + rebuild-index.
M3: + reindex-changed-paths (only when caller passes `paths`).
M3.5: + git auto-commit (always — non-git dirs warn-and-skip).

`paths` is the second arg, not a LogEvent field, because LogEvent is the
persisted log.md row shape. `paths` is ephemeral — purely for routing the
reindex side-effect AND for staging the right files in the git commit.

Returns the new git commit SHA, or None when no commit was created (no-git
repo, or nothing to commit). Callers fold this into their JSON output.
"""
from __future__ import annotations

import os
import sys
import traceback
from pathlib import Path

from pkm.store import git as gitmod
from pkm.store.embedder import get_embedder
from pkm.store.index_db import connect
from pkm.store.log import LogEvent, append_event
from pkm.store.toc import rebuild_index

_LOG_REL = "data/log.md"
_INDEX_REL = "data/index.md"


def post_mutation(root: Path, event: LogEvent,
                  paths: list[str] | None = None) -> str | None:
    """Append event → rebuild TOC → reindex paths → git commit.

    Returns the 40-char commit SHA, or None if no commit was made (no git
    repo, or nothing to commit). Reindex failures are swallowed as warnings
    (filesystem is the source of truth); git failures likewise warn-and-skip.
    """
    append_event(root, event)
    rebuild_index(root)

    if paths:
        try:
            reindex_changed_paths(root, list(paths))
        except Exception as e:
            print(f"warning: post_mutation reindex failed: {e}", file=sys.stderr)
            if "PKM_DEBUG" in os.environ:
                traceback.print_exc(file=sys.stderr)

    return _git_commit_for(root, event, list(paths) if paths else [])


def reindex_changed_paths(root: Path, paths: list[str]) -> None:
    from pkm.commands.reindex import _bucket_for, _index_one, _vec_opted_in

    conn = connect(root)
    try:
        embedder = get_embedder()
        vec_opt = _vec_opted_in(root)
        for rel in paths:
            abs_p = root / rel
            if not abs_p.exists():
                continue
            bucket = _bucket_for(root, abs_p)
            if bucket is None:
                continue
            _index_one(conn, root, bucket, abs_p, embedder, vec_opt)
        conn.commit()
    finally:
        conn.close()


def _git_commit_for(root: Path, event: LogEvent, paths: list[str]) -> str | None:
    """Stage paths + log + index, commit with `pkm <type>: <ref>` message."""
    if not gitmod.is_git_repo(root):
        print("warning: not a git repo, skipping commit", file=sys.stderr)
        return None
    stage = list(paths) + [_LOG_REL, _INDEX_REL]
    message = f"pkm {event.type}: {event.ref}"
    try:
        return gitmod.commit_paths(root, stage, message)
    except Exception as e:
        print(f"warning: git commit failed: {e}", file=sys.stderr)
        if "PKM_DEBUG" in os.environ:
            traceback.print_exc(file=sys.stderr)
        return None
```

```python
def commit_paths(root: Path, paths: list[str], message: str) -> str | None:
    if not is_git_repo(root):
        return None

    if paths:
        # `git add -A -- <paths>` stages adds, modifications, AND deletions
        # for the given pathspecs (even if the path is gone from disk).
        # This is what we want when a mutation removes a file.
        rel_paths = [str(p) for p in paths]
        _run(["git", "add", "-A", "--", *rel_paths], cwd=root)

    diff = _run(["git", "diff", "--cached", "--name-only"], cwd=root)
    if not diff.stdout.strip():
        return None

    _run(["git", "commit", "-q", "-m", message], cwd=root)
    head = _run(["git", "rev-parse", "HEAD"], cwd=root)
    return head.stdout.strip()
```

## Notes for the executor

- **`git add -A`** is the keystone for handling deletions. Don't filter missing paths from `commit_paths` — the whole point is that `rm` mutations need to stage deletions.
- **Initial commit at `pkm init`** must include `.gitignore` so the very first mutate doesn't accidentally stage `.pkm/index.db` (created by reindex when M3.13 fixtures or smoke tests run after init).
- **Recursion guard not needed** — `commit_paths` doesn't call `post_mutation`. The chain is one-way.
- **Test `tmp_path` directories**: tests that bypass `pkm init` (bare scaffold) will hit the warn-and-skip path. The warn goes to stderr; pytest captures it. Don't `caplog`/`capsys` it unless the test explicitly checks the warning text.
- **`PKM_TEST_STUB_EMBEDDER=1` is preset by conftest** — never set/unset it inside a test except as already done in M3 tests.
- **Don't widen scope.** No `--no-git` flag. No GPG signing. No `pkm git ...` wrapper. No commit-message hooks.
